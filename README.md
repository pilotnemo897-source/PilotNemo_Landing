# PilotNemo_Landing | NexusDigital Premium Business Landing Page

A complete, production-ready, client-conversion landing page for **NexusDigital**, a premier digital growth and technology partner.

![NexusDigital Landing Page](https://raw.githubusercontent.com/pilotnemo897-source/PilotNemo_Landing/main/public/preview.png)

## 🚀 Key Features

- **Strategic Client-Conversion Journey**: Follows a high-impact psychological conversion funnel designed specifically for business decision-makers.
- **Interactive Growth Dashboard**: Real-time floating analytics dashboard in the hero section displaying traffic (+148%), lead growth (+72%), revenue ($2.4M), and client satisfaction metrics.
- **Interactive Problem/Solution Cards**: 4-card interactive dilemma section with hover lifts, glowing blue borders, and arrow transitions.
- **Connected Business Ecosystem**: Deep navy section featuring an animated 5-stage pipeline (*Brand Strategy → Website → Marketing → Leads → Growth*).
- **Full-Stack Services Grid**: 7 service cards focusing on business outcomes (Digital Marketing, Full-Stack Web Dev, Mobile Apps, Branding, UI/UX, Business Development, Custom Software).
- **5-Step Process Roadmap**: Horizontal desktop and vertical mobile timeline progression (*Understand → Strategize → Design → Build → Grow*).
- **Interactive Solution Finder**: Mini digital consultation tool allowing visitors to select business goals and receive instant dynamic package recommendations.
- **Validated Contact Form & Micro-Interactions**: Split layout with WhatsApp, Email, Call channels and a full lead form with celebratory confetti on submission.
- **Responsive & Accessible**: Engineered with modern React architecture, Tailwind CSS, Framer Motion animations, and full mobile responsiveness.

---

## 🛠️ Technology Stack

- **Framework**: React 18 + Vite
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti

## 💻 Getting Started

### Prerequisites

- Node.js v18+
- npm v9+

### Installation & Local Development

```bash
# Clone the repository
git clone git@github.com:pilotnemo897-source/PilotNemo_Landing.git

# Navigate into project folder
cd PilotNemo_Landing

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
```
